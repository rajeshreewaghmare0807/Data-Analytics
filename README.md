# 📊 Student Data Analysis

This project focuses on **student data cleaning, preprocessing, and visualization** using Python.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## 📁 Dataset

The dataset contains student information such as:

- Roll Number
- Name
- Age
- Email ID
- Subject
- Marks

## 🔧 Data Preprocessing

The project includes:

- Removing unnecessary columns
- Handling missing values
- Replacing `NONE` values with missing values
- Filling missing Age and Marks using mean
- Interpolating missing Roll Numbers
- Correcting student names
- Correcting email IDs
- Filling missing subjects
- Converting Age and Marks into integer format

## 📈 Data Visualization

A bar chart is created using **Matplotlib** to visualize:

**Subject vs Marks**

The chart uses different colors for each student's marks.

## 🎯 Objective

The main objective of this project is to practice **data cleaning, preprocessing, and visualization** using Python and understand how raw student data can be prepared for analysis.

## 👩‍💻 Tools

**Python | Pandas | NumPy | Matplotlib | Google Colab**

## 📌 Conclusion

This project demonstrates a basic data analysis workflow, starting from raw student data and ending with a cleaned dataset and visual representation of student marks.
